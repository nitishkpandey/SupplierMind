Hybrid retrieval
Fusing semantic search with structured filtering so each covers the other's weakness
Query with constraints
meaning + hard thresholds (certification, capacity, location)
Two strategies run in parallel
Semantic search
vector similarity — captures meaning, but has no notion of a numeric threshold
Structured filter
SQL predicates + geospatial — exact, but does not understand meaning
Merge candidates
combine both result sets
Candidate set — relevant and constraint-consistent
both topically on-target and within the hard limits
Neither strategy suffices alone: similarity ignores thresholds, and filters ignore meaning.
