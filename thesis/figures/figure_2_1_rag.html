Retrieval-augmented generation (RAG)
Grounding a language model's answer in documents retrieved from a corpus
User query
a natural-language request
Embed query
encode the text as a vector
Retrieve top-k documents
the most similar records from the corpus
Assemble prompt
query + retrieved documents as context
Language model
conditions its answer on the retrieved documents
Grounded answer
based on real, checkable text
Retrieval replaces the model's parametric memory with real documents, removing the most flagrant hallucinations.
