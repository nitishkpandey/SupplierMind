## §1 Bugs — 26/26 resolved

### HIGH

1. **OAuth login-CSRF (no `state`)** — FIXED. `state` = `secrets.token_urlsafe(32)`, stored in
   short-lived HttpOnly `oauth_state` cookie, verified with `compare_digest` in the callback
   before any token exchange. Applied to **both Google and GitHub** (GitHub had the same hole).
   Tests: `tests/unit/test_oauth_security.py`.
2. **Tokens in redirect query string** — FIXED. Fragment delivery (`#access_token=…`); fragments
   never reach servers, logs, or Referer. `AuthCallbackPage.tsx` parses the hash. Deliberately
   skipped: one-time exchange-code endpoint (add if tokens must leave the URL bar entirely).
3. **Blocking `time.sleep(20)` in async ingest** — FIXED. `await asyncio.sleep(20)`; sync
   Voyage/Milvus `add_suppliers` offloaded via `asyncio.to_thread` (`services/ingestion.py`).

### MED

4. **Geo filter truthiness (discovery_agent)** — ALREADY FIXED at HEAD by `0df591e` (`is not None`
   throughout); audit ran on the prior revision. No change needed.
5. **Confidence parsing (parser_agent)** — FIXED. try/except float(); real `0.0` survives,
   `"high"`/`None` → 0.5 instead of raising.
6. **IDs returned after rollback (external_discovery)** — FIXED. Except path returns `[]`.
7. **Postgres/Milvus non-atomic ingest** — FIXED. Vector add moved before `commit()`; Milvus
   failure now rolls back Postgres. Residual (`ponytail:` comment): commit-failure after vector
   add leaves orphan vectors, harmless since search resolves via Postgres.
8. **Broad except masks DB failure (discovery_agent)** — FIXED. Re-raises → `pipeline_status="failed"`,
   distinct from empty results.
9. **`?limit=0` → 500 (queries.py)** — FIXED. `Query(20, ge=1, le=100)` / `Query(0, ge=0)`. Test added.
10. **Rate-limiter lock held across sleep + DB write** — FIXED. Lock only for window bookkeeping;
    sleep and audit write outside. `ponytail:` global lock kept; per-model locks if contention appears.
11. **Per-request filter on root logger** — FIXED. `contextvars.ContextVar` + one filter installed once.
12. **Rate-limit identity + unbounded dict** — FIXED. `X-Forwarded-For` first hop preferred;
    expired windows pruned (≤ once/60s).
13. **SSRF in page_fetcher** — FIXED. http/https only; every resolved address must be `ip.is_global`
    (blocks 169.254.169.254, loopback, private, reserved); redirects hopped manually (max 5) with
    re-validation per hop. Tests: `tests/unit/test_page_fetcher_ssrf.py`. Residual: DNS-rebinding
    TOCTOU (closing it needs an IP-pinning transport).
14. **Fake health check** — FIXED. Real probes: DB `SELECT 1` (fail → 503), vector-store count and
    cache round-trip (fail → degraded, 200). `ponytail:` split /livez vs /readyz if ever needed.
15. **Stale map (SupplierMap.tsx)** — FIXED. Effect depends on `[results, constraints]` with full
    teardown; `cancelled` flag guards the async leaflet import.
